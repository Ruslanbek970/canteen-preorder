# С чего начать

## Что лежит в папке

- `CLAUDE.md` — правила для Claude Code. Он читает этот файл сам при каждом запуске.
- `docs/SPEC.md` — полное ТЗ проекта: роли, правила, API, экраны, фоновые задачи, DevOps и 14 фаз работы.
- `docs/schema.sql` — схема базы данных (её же можно запустить в pgAdmin).
- `docs/er_diagram.png` — ER-диаграмма.
- `docs/PROGRESS.md` — журнал. Claude Code отмечает в нём, что сделано.

## Что установить

1. Git.
2. Docker Desktop (с Docker Compose).
3. Node.js 20 LTS и Python 3.12 — желательно, чтобы запускать тесты и линтеры без Docker.
4. Claude Code.

## Первый запуск

1. Распакуйте архив в папку `canteen-preorder`.
2. В терминале в этой папке:
   ```
   git init
   git add .
   git commit -m "docs: project spec"
   ```
3. Создайте пустой репозиторий на GitHub и привяжите его (`git remote add origin ...`, `git push -u origin main`).
4. Запустите в этой папке Claude Code и вставьте промпт для фазы 0 (ниже).

## Как вести работу

- **Одна фаза — одна сессия.** Когда фаза готова и закоммичена, начните новую сессию (`/clear`) и вставьте промпт следующей фазы. Так у Claude Code чистый контекст, а всё важное он прочитает из `CLAUDE.md`, `SPEC.md` и `PROGRESS.md`.
- **Проверяйте сами** пункт «Готово, когда» из SPEC перед тем, как идти дальше: откройте сайт, нажмите кнопки, посмотрите тесты.
- **Читайте изменения.** На защите код будете объяснять вы. После каждой фазы попросите: «объясни, что ты сделал в этой фазе, по файлам, простыми словами».
- **Если что-то сломалось**, опишите, что вы делали, что ожидали и что получили, и вставьте текст ошибки целиком.

## Промпт для фазы 0

```
Прочитай CLAUDE.md, docs/SPEC.md и docs/PROGRESS.md целиком.
Мы начинаем проект с нуля. Выполни Фазу 0 «Каркас» из раздела 16 SPEC.
Сначала покажи план задач для этой фазы, потом сделай их.
В конце: запусти линтеры и тесты, проверь пункт «Готово, когда»,
обнови docs/PROGRESS.md, сделай коммит и коротко расскажи мне,
что сделано и как это проверить у себя.
```

## Промпт для каждой следующей фазы

Замените N и название:

```
Прочитай CLAUDE.md, docs/SPEC.md и docs/PROGRESS.md.
Выполни Фазу N «Название» из раздела 16 SPEC.
Сначала покажи план задач, потом сделай их.
Не трогай то, что не относится к этой фазе, кроме исправления найденных багов
(их запиши в PROGRESS.md).
В конце: линтеры и тесты зелёные, пункт «Готово, когда» выполнен,
PROGRESS.md обновлён, коммит сделан. Расскажи, что сделано и как проверить.
```

## Полезные промпты по ходу

- «Объясни, как работает создание заказа: от нажатия кнопки до записи в базу, по файлам.»
- «Найди слабые места в коде фазы N: баги, гонки, дыры в правах доступа. Сначала список, потом исправления.»
- «Сделай скриншоты всех экранов студента на ширине 360 px через Playwright и сохрани в docs/screenshots.»
- «Подготовь docs/demo-script.md по разделу 17 SPEC с точными шагами и демо-аккаунтами.»

## Как разделить работу в команде

Claude Code пишет код, но каждый в команде должен уметь объяснить свою часть:

- backend: заказы, слоты, оплата, статусы, тесты;
- frontend: экраны студента, кухни и кассы;
- аналитика: прогноз спроса, отчёты, нагрузочный тест;
- DevOps: Docker, CI/CD, сервер, мониторинг, бэкапы.
